# Umanni visual identity

Static visual identity deliverable for the evaluation project. This is an unofficial use of public Umanni assets without an express brand license. Read the [canonical notice](LICENSES/UMANNI-NOTICE.md) before using any material.

## Evidence vocabulary

- `observed`: verified public evidence, with source and date.
- `decided`: an explicit decision in the approved branding brief.
- `adapted`: a recommendation produced for this project, including accessibility adaptations; never an official Umanni brand rule.

## Delivery status

Source preservation is in progress. Boards, tokens and component documentation are not yet validated. See [provenance](PROVENANCE.md) and the [execution report](../umanni-vault/EXEC-001-BRANDING.md) for actual evidence and remaining work.

The brand has two permitted visual variants: the public blue horizontal signature and the public blue symbol. The byte-preserved favicon is a technical package, not a third logo. The public symbol has a different blue from the horizontal PNG; both original files are preserved without recoloring.

## Scope

This PR contains static assets and specifications. The broader requested navigable prototype requires its own specification and topic PR. No application behavior is implied by a static composition. Dark mode is absent because available public information is insufficient to define it faithfully.
