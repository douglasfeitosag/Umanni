# Glossário

| Conceito | Significado neste projeto |
| --- | --- |
| SDD | Especificar o que entregar, planejar como fazer, dividir em tarefas e verificar consistência antes de executar. |
| Spec Kit | Ferramentas e templates do GitHub para apoiar SDD. A versão está em TOOLING.md. |
| Constituição | Regras estáveis do projeto, que limitam os planos e prompts. |
| ADR | Registro de uma decisão arquitetural com razões e consequências. |
| BDD | Descrever comportamentos como Dado/Quando/Então e ligar cenários a requisitos e testes. |
| TDD | Teste falha primeiro, implementação faz passar e refatoração preserva o comportamento. |
| Monolito | Uma aplicação com ciclo de entrega conjunto, mesmo com processos web e de jobs separados. |
| MVC | Divisão entre dados/regras dos modelos, apresentação e controladores de requisições. |
| Inertia | Integra páginas React aos controladores Rails. |
| Policy | Regra explícita sobre quem pode agir sobre cada registro. |
| Serviço de aplicação | Coordena operações com várias etapas, como uma importação. |
| Solid Queue | Executa trabalhos em segundo plano usando banco de dados. |
| Solid Cable | Armazena/transmite mensagens de atualizações ao vivo para Action Cable. |
| Design token | Valor nomeado de cor, fonte, espaçamento ou outro atributo visual reutilizável. |
| Componente | Unidade reutilizável de interface com estados, comportamento e responsabilidades definidos. |
| CI / runner | Verificações automáticas / processo que executa essas verificações na máquina escolhida. |
| PR / merge | Proposta de alteração para revisão / incorporação à branch principal. |
| Docker Compose | Define e inicia os serviços locais e suas redes/volumes. |
| EXEC | Relatório da executora: o que fez, evidências, limitações e próxima ação. |
| Handoff | Passagem de contexto enxuta para uma nova sessão. |
