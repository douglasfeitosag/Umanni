# Umanni 0.4.0

Release menor de importação administrativa local. Inclui CSV/XLSX assíncrono, worker Solid Queue, progresso persistido, relatório seguro por linha e definição única de senha inicial para contas importadas.

## Incluído

- Upload administrativo limitado de CSV UTF-8 e XLSX de uma planilha, com pré-validação e rejeição estrutural antes da fila.
- Lotes persistidos, processamento idempotente no worker `imports`, resultados públicos por linha e atualização privada via Solid Cable.
- Volume Active Storage compartilhado entre web e worker, com restart e operação local verificados.
- Formulário administrativo acessível para definir uma senha inicial somente quando a conta importada ainda não possui credencial.

## Limites

Não inclui e-mail, convite, recuperação de senha, retry manual, cancelamento, exportação, Redis, CI/runner, deploy ou Backlog.
