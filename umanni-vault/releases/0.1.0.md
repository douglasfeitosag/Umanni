# Umanni 0.1.0

Primeiro marco público documentado do projeto. Esta versão reúne a base de governança, a identidade visual estática verificada, o hub de consulta e um protótipo visual navegável com dados fictícios. É uma entrega pré-aplicação e não representa um sistema produtivo.

## Incluído

- PR #1 — organização da documentação no vault dedicado.
- PR #2 — planejamento revisado da identidade visual.
- PR #3 — assets públicos verificados, fontes, licenças e procedência.
- PR #4 — identidade estática, tokens, playbook, componentes e composições.
- PR #5 — hub navegável de referência visual.
- PR #6 — protótipo visual navegável, responsivo e descartável.
- PR #7 — governança para abertura automática da revisão final independente.
- PR #8 — integração do hub revisado na principal.
- PR #10 — política de versões, changelog, notas e evidência de fechamento de `0.1.0`.

## Evidência principal

- 28 testes centrais do protótipo aprovados, com 100% de linhas/funções e 92,12% de ramos.
- Oito cenários finais de navegador aprovados nas viewports 390×844, 1280×720 e 1440×1024.
- Assets, licenças, navegação por teclado e PNGs finais inspecionados conforme os relatórios EXEC versionados.
- Revisões independentes e gate `review-ledger` vinculados aos HEADs exatos de cada entrega.

## Limites conhecidos

- Não há aplicação Rails, autenticação real, persistência, importação CSV/XLSX, jobs, Docker Compose, CI de aplicação ou runner de produção.
- O protótipo simula estados visuais; não deve ser usado como prova de regras funcionais.
- A identidade é uma candidata avaliativa não oficial baseada em fontes públicas, sem alegação de autorização da Umanni.
- Somente o tema claro sustentado por evidência pública integra a versão.
- O polimento de quebra do slogan com texto a 200% está explicitamente adiado na issue #9, milestone `Backlog`, por não quebrar o fluxo principal.
