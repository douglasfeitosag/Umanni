# Umanni 0.4.1

Correção de reprodutibilidade para a avaliação local. Esta versão não acrescenta um fluxo de produto: torna executável e verificável o roteiro de avaliação já entregue.

## Incluído

- README com pré-requisitos explícitos, clone e seleção de versão, `.env` privado, geração local de `SECRET_KEY_BASE`, gates, delivery, bootstrap, desenvolvimento e encerramento restrito ao projeto nomeado.
- Delivery inicializado com `web` e `worker` juntos, com explicação verificável de `/up` como liveness e `/ready` como banco/migrations.
- Bootstrap do primeiro administrador no delivery local somente por opt-in explícito, preservando as proteções existentes contra uso produtivo não intencional, banco/host incorretos, confirmação inválida, vazamento de senha e duplicidade.

## Validação

- O candidato passou `bin/check` com 93 RSpec, 95,29% de linhas Ruby, 23 Vitest, 66 Playwright, RuboCop e Brakeman sem alertas.
- `bin/check-delivery` passou os 18 cenários production-like, incluindo worker, volume compartilhado, restarts, healthchecks, erros seguros e falha de banco.
- Um worktree isolado comprovou configuração privada, startup de web+worker, `/ready`, `/up`, bootstrap criado/no-op e shutdown do projeto isolado.

## Limites

Não inclui CI/runner, deploy, e-mail, convite, recuperação de senha, API paralela, Redis, extras de plataforma ou issue #9. A validação arm64 não prova amd64.
